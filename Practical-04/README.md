# Practical 4 — Validation and command parsing

Validate mobile, email, PAN and IFSC strings. Convert a command string to a record and format a statement.

Run `run.bat` on Windows or `bash run.sh` on Linux/macOS. Compile only this folder. Requires JDK 17+.

Expected result: The validators distinguish valid and invalid values. The command parser and statement formatter produce readable output.
