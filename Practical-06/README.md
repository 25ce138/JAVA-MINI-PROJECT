# Practical 6 — Interfaces packages and runnable JAR

Use interfaces, a default method, a marker interface, a lambda and packages. Build a runnable JAR.

Run `run.bat` on Windows or `bash run.sh` on Linux/macOS. Compile only this folder. Requires JDK 17+.

Expected result: The anonymous rule and lambda return the same result. The default interface method calculates yearly interest.
