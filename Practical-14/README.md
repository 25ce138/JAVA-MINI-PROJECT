# Practical 14 — Complete MiniBank application

Connect a simple console menu to account opening, deposits, withdrawals, transfers and statements. Save accounts on exit and reload them at startup. Verify behavior with JUnit 5.

Run `run.bat` on Windows or `bash run.sh` on Linux/macOS. Compile only this folder. Requires JDK 17+.

Expected result: The demonstration finishes with balances of 5500 and 3000. Restarting reloads both accounts. All seven JUnit tests pass.
